## Data safety

Answers for releases that contain family walls (1.0.0 and later).

- **Data collected:** Yes – only for features the user chooses: an encrypted memory capsule link,
  the wall display on another screen, and family walls. Backup files never reach GK Coding;
  Android cloud backup is off for the app (device-to-device transfer only).
- **Data shared:** No. No advertising or analytics. (Google processes sign-in as a service
  provider; reports stay with GK Coding.)
- **Encrypted in transit:** Yes.
- **Account creation:** Yes, optional, only for family walls (Google Sign-In). The user's own wall
  needs no account.
- **Account deletion:** Yes, in the app (Family walls → Account → Delete account) and on the web at
  https://gkcoding.dev/lifethreads/delete-data. It deletes the walls the account owns with all
  memories and photos, the user's memories on other walls, and the account.
- **Personal info → User IDs:** Collected (family walls): the Google Sign-In account identifier.
  Purpose: app functionality, account management, fraud prevention and security (moderation).
  Not shared.
- **Personal info → Name:** the display name a member chooses for a family wall. It is end-to-end
  encrypted; declare it as collected for app functionality if in doubt.
- **Photos and videos:** Collected, user-initiated, app functionality. The wall display snapshot is
  stored unencrypted until the session expires (at most 60 minutes). Family wall photos are resized
  and end-to-end encrypted on the device; GK Coding stores only ciphertext and never receives the
  key. Shared capsules are encrypted and expire.
- **Other user-generated content:** Collected (family walls), for app functionality and moderation.
  Titles and stories are end-to-end encrypted, except when a user reports a memory: the report sends
  that memory's decrypted title and story, the reason and an optional note.
- **Location:** optional place names from photos, used for app functionality; included in a
  capsule, a wall display or a family wall memory only if the user shares it. Map tiles come from
  OpenFreeMap, which sees the viewed map area.
- **Financial info → Purchase history:** the owner's Play purchase token is sent to GK Coding to
  verify Premium; GK Coding stores whether it is active and when it ends. Payments are processed by
  Google Play.
- **App activity, app info and performance, device IDs:** Not collected.

- Block users or content: **Yes** (block a member; owners remove members and memories)
- Report users or content: **Yes** (reviewed within 24 hours)

```text
LifeThreads has no public feed, no profiles, no comments, no chat and no user discovery. Users can share one encrypted memory capsule through a private link that expires and can be revoked. Family walls are private, end-to-end encrypted walls shared only with people invited by a one-time link that expires within 7 days. Before posting, users accept terms with zero tolerance for objectionable content. ## Build, signing and permissions
```

```bash
flutter build appbundle --release        # build/app/outputs/bundle/release/app-release.aab
```

- Signed with the upload key from `android/key.properties` (alias `lifethreads`, keystore
  `release/lifethreads-release-key.jks`; never commit either). Play App Signing re-signs for users.
- Maps use OpenFreeMap without a key; `--dart-define=MAPTILER_KEY=…` switches to MapTiler (rotate
  the key first, see `docs/maptiler_key_rotation.md`).
- Backup: `allowBackup` is on, but `data_extraction_rules.xml` / `backup_rules.xml` exclude cloud
  backup; only device-to-device transfer moves the app's data.

Permissions in the manifest and why (Play asks about some of them):

| Permission | Used for |
|---|---|
| `INTERNET` | map tiles, Play Billing, capsule sharing, wall display, family walls |
| `CAMERA` | scanning the wall display QR code, taking memory photos |
| `READ_CONTACTS` | optional: importing a person into a memory |
| `READ_MEDIA_IMAGES`, `READ_MEDIA_VISUAL_USER_SELECTED` | choosing photos for memories (core feature; answer the **Photo and video permissions** declaration accordingly) |
| `READ_EXTERNAL_STORAGE` (≤ API 32), `WRITE_EXTERNAL_STORAGE` (≤ API 29) | photo access and saving stories on old Android versions |
| `ACCESS_MEDIA_LOCATION` | optional place from a photo's EXIF data |
| `POST_NOTIFICATIONS`, `RECEIVE_BOOT_COMPLETED` | On this day and backup reminders, rescheduled after a restart |

App Links: `https://gkcoding.dev/lifethreads/share/…`, `https://lifethreads.gkcoding.dev/share/…` and
`https://lifethreads.gkcoding.dev/family/join` (Digital Asset Links must list the upload and Play
App Signing SHA-256 fingerprints).
