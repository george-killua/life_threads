# Public Android Launch Runbook

Use after closed beta exit criteria in `docs/closed_beta_checklist.md` are met.

## Pre-launch

- [ ] Production AAB signed with release keystore
- [ ] Built with rotated `MAPTILER_KEY`
- [ ] Play listing from `docs/play_store_content.md`
- [ ] At least 6 screenshots + feature graphic uploaded
- [ ] Privacy + terms URLs live and linked in Play Console + in-app Settings
- [ ] Data Safety form matches `docs/privacy_policy.md`
- [ ] Content rating complete; category Lifestyle
- [ ] Monthly subscription `lifethreads_premium_monthly` active
- [ ] Soft-ask beta testers for private feedback before public reviews

## Go-live

1. Publish production with staged rollout: 20% → 50% → 100%
2. Monitor Play Console crashes and ANRs after each stage for at least 24h
3. Post first demo video (couple / travel / family)
4. Add landing page link on GK Coding site
5. Share Play Store link on LinkedIn
6. Track installs, crashes, listing conversion, and feedback themes

## First week (stability only)

- Fix crash and data-loss bugs first
- Respond to useful feedback
- Improve screenshots if conversion is weak
- Publish remaining short videos
- Do not add large new features before stability is proven
